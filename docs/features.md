# Feature reference

Everything in the window, with its keys and what VoiceOver hears. The [README](../README.md) has the short version.

- VoiceOver rotors (VO-U) on the conversation: Messages, Your Messages, Tool Calls, Marked Messages, Code Blocks, Headings and Links (the headings and links in Claude's replies, including links inside lists and tables). In a long conversation they reach earlier pages too: Marked Messages lists a mark made before the latest page, and moving back through any of them carries on into the page before.
- While earlier messages are showing, a Latest Message button sits over the end of the conversation. It goes to the end, as the Claude app's does, and gives the latest message keyboard focus. VoiceOver finds it last in the conversation; with VoiceOver, Command-Control-End (Go to Latest Message) is the dependable way to move to the message.
- Go > Previous Message (Command-Control-Up), Next Message (Command-Control-Down) and Go to Latest Message (Command-Control-End, or Fn-Command-Control-Right on a laptop) move between your messages and Claude's replies, skipping tool calls and thinking. Each scrolls the message to the top of the conversation and asks VoiceOver to move there. They count from the message you last moved to while it's still on screen, otherwise from the top of what's showing, and say "First message." or "Last message." at the ends instead of wrapping.
- A projects sidebar, like the Claude app's Code section. Every folder with saved conversations is a section named by the folder, most recently used first, with its conversations under it, newest first, one line each. A worktree is named "repository · worktree", and folders that share a name add where they are ("enchanted · ~/Documents"). The Claude app's no-folder sessions are one "This computer" section at the end; throwaway folders in the system's temporary space are left out. Each project name is a heading (VO-Command-H moves between projects); the + beside it, or the heading's New Conversation action (VO-Command-Space), starts a conversation there. Sections fold and stay folded. A dot marks a conversation that's working in any window, and VoiceOver hears "working" after its title. The accent-colored dot marks one that "needs your answer" (a tool to allow, a plan, a question) and one left "unread", which finished while its window wasn't in front or was marked unread; looking at it clears the mark. Selecting a conversation restores its messages and continues it with Claude's context, moving the window to its folder. File > New Session is Command-N (the toolbar's New Session also answers Shift-Command-N), and New Window is Option-Command-N. View > Hide Sidebar (Command-B) leaves the conversation alone in the window. Command-F (Edit > Search Conversations) searches titles and first prompts across every project, ignoring case and accents, and VoiceOver hears the match count once typing pauses. Escape clears the search. Each conversation's actions (VO-Command-Space, or right-click) are Pin or Unpin, Rename, Mark as Unread or Read, Open in New Window, Archive or Unarchive, and Delete; pinned conversations move to a Pinned section first. Archive takes a session out of the list and keeps it; Session > Show Archived Sessions lists archived ones again, read as "archived". Choosing a session that's already open in another window, from the sidebar, Command-K, Command-1 to 9 or Open in New Window, brings that window forward instead of opening it twice. Unread marks are kept across launches. Delete asks first and moves the conversation to the Trash.
- A saved conversation reopens where you were reading it, after switching sessions or relaunching, at the same place in the message even if the window or text size changed. Keyboard focus stays in the message field. One read to the end reopens at the end, and so does a place older than the latest page of a long conversation.
- Replies rendered as Markdown with ChatMarkdownKit. VoiceOver reads the text without Markdown symbols. A reply is a group named "Claude": VO-Shift-Down goes in, and each heading, paragraph, list, code block, quote, table and link inside is its own stop. Lists say "1 of 3" for each item, and a code block is named by its language and length ("Swift code, 3 lines").
- A sheet asking Allow or Deny before a tool runs, asking as the Claude app does ("Allow Claude to run git status?", "Allow Claude to edit App.swift?") and showing the command or path (Return answers neither: Escape denies, Command-Return allows). In Plan mode, Claude's plan arrives as "Claude proposed a plan", drawn as formatted text, with Reject, Revise… (a "What should change?" note Claude plans again from), Accept and Allow Edits, and Accept. While it waits, the tool's row reads "waiting for permission". A running tool's row says how long it has run ("Tool, running 40 seconds") when you land on it. When Claude asks you to choose, a sheet of radio buttons and checkboxes appears. While either sheet waits, Command-1 to 9 don't switch sessions behind it.
- Model, effort and permission-mode menus in the toolbar. The model list comes from the CLI. View > Customize Toolbar offers Icon and Text, which puts a word under each toolbar symbol.
- Each message's actions (VO-Command-Space, or right-click) include Copy message and Mark message. A finished reply also offers "Open link: …" for each web or mail link in it and "Copy code block" for each code block. Inside a reply, every block offers Copy message and Mark message too, and a code block offers Copy code.
- A side panel (F6 moves between it and the message field) with a code editor that has line numbers and a line and column readout, a diff reader, and Uncommitted Changes (Command-Shift-D). Text zoom sizes the editor and diffs too. Quitting, or closing a window, with edits not yet saved asks first (Save, Cancel, Don't Save). Saving keeps a file's Windows line endings and its hard links, and leaves a read-only file alone. A large file shows at once and is colored in the background (past 1 MB it stays plain). The caret stays where it was when Claude changes the open file or you go Back to it. In Go to File (Command-P), Return opens the first match and Down Arrow moves into the list. Open in New Window takes the file's unsaved edits along.
- The Terminal panel (Command-J) runs your login shell as Terminal does. Control-C, Control-D, Control-Z and Control-Backslash work in its command field. While a program asks for a password (sudo, ssh) the field becomes a secure Password field. Output that keeps coming is announced at least every 3 seconds.
- Slash commands: typing "/" in the message field lists the commands the CLI offers, its built-ins plus your skills and plugin commands. Down and Up move through them while the keyboard stays in the field, and VoiceOver says each command and what it does. Tab completes, Return chooses (a command that takes more, like /model, waits for it), and Escape closes the list. The interaction follows Clarc's picker.
- Image attachments through Add Image… in the Add (+) menu, by dropping files on the window, or by pressing Command-V in the message field with an image (a screenshot, a copied image file) on the clipboard; text on the clipboard still pastes as text. Copied files of any other kind paste as @-mentions, as a drop does. What's typed and attached stays with its session when you switch to another. VoiceOver hears "Attached …". Each chip shows a small preview the right way up, decoded off the main thread, and VoiceOver reads its full file name and Remove button.
- Messages sent while Claude works wait in a queue above the message field, read as "2 queued messages" with the next one shown. Expanding it lists each message with Edit and Remove, so one can be changed or taken back before Claude sees it; a message being edited waits for Save Message or Cancel Edit. Stop and errors pause the rest until Resume, and Reconnect appears if the CLI exits. The queue belongs to the window's conversation. Switching conversations clears it, but what was queued goes back into that conversation's message field, kept with its draft until you return; closing the window clears it. The message field itself follows the conversation too: a draft and its images stay with the session they were typed in.
- Stop (Escape in the message field, or Command-Period) while Claude is working. Switching to another conversation, closing the window or quitting mid-reply stops it the same way, so what Claude wrote so far is still there when you come back. Escape closes the slash command list first when it's showing. VoiceOver announces when a reply finishes or stops.
- Bigger Text, Smaller Text and Actual Size in the View menu (Command-Plus, Command-Minus, Command-0) size the conversation and the message field on top of the system text size. VoiceOver says the new size.
- The Claude app's keys, each listed in a menu so VO-M and Help's search find it. Session menu: Search or Start a Session (Command-K), Choose Mode (Shift-Command-M), Choose Model (Shift-Command-I), Choose Effort (Shift-Command-E, the model menu's effort levels alone), Rename Session (Option-Command-R), Pin Session (Option-Command-P), Archive Session (Option-Command-A), Mark as Unread (Option-Command-U), Reopen Closed Session (Shift-Command-T), Fork Session (Option-Command-O, which carries on from a copy titled "… (fork)" and leaves the original as it was), and Go to Session, which lists the sidebar's first nine sessions by title and opens them with Command-1 to Command-9 (a folded project's sessions aren't counted). In the mode and model menus, number keys choose the first nine items. Help > Keyboard Shortcuts (Command-Slash) lists every key in the menu bar, read off the menus themselves, one menu per heading, each row read as "New Session, Command-N", then an "In the Window" heading for keys on the window's buttons (Send, Stop, F6, Open File, Back, Save, pasting an image). New Session and Reopen Closed Session still work after the last window closes. The model button names the model it will run ("Fable 5.1"), not "Default (recommended)". View menu: Show Files (Shift-Command-F), Go to File (Command-P, which starts in the files filter), Show Uncommitted Changes (Shift-Command-D), Show Terminal (Command-J), Show Side Chat (Command-Semicolon), Close Panel (Command-Backslash) and Expand Panel (Shift-Command-Backslash), which lays the panel over the session for reading at a large size and puts it back the same way. Opening the side chat, Terminal or Files moves VoiceOver into it along with the keyboard, and the panel's close button is named for what it closes ("Close Side Chat"). Command-K's palette lists sessions whose title matches what's typed before ones that only match in their first prompt. A tool row with output has a disclosure button, also offered as Show Output or Hide Output in its actions (VO-Command-Space) and its context menu, and the choice stays while the row updates. View > Show Tool Output (Control-O, the Claude app's Verbose view) sets every row at once, drawing each tool's output under its row, read with it by VoiceOver, in live and reopened sessions. View > Group Sessions By switches the sidebar between Folder and Date (Today, Yesterday, Previous 7 Days, Older), where each row ends with its project ("…, in IA"). The line under the session title names the git branch ("ClaudeNative · main", heard as "ClaudeNative, on branch main").
- Optional sound cues (View > Sound Cues, off by default) for a tool starting, succeeding or failing, Claude finishing, and Claude needing permission. View > Play the Sound Cues plays each one and says what it means. View > Announce When Claude Finishes turns off the spoken "Claude finished.", which ends VoiceOver's reading of a reply once its current line is done.
- Summaries of Claude's thinking, as a quieter row read as "Thinking" while it runs and "Thought" once it's done. They appear at higher effort levels; the Messages rotor skips them.
